## Tagging tasks

Add one or more hashtags anywhere after a task's command word to organize the task. Tags are case-insensitive,
displayed in lowercase, and duplicate tags are stored only once.

Examples:

* `todo watch a movie #fun #weekend`
* `deadline submit report /by 2026-09-15 #school`
* `event team meeting /from 2026-09-20 0900 /to 2026-09-20 1000 #work`

Use the `find` command to find tasks by tag, e.g., `find #fun`.
